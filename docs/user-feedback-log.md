# Sahod User Feedback Log

This log tracks the 50-user Level 5 feedback cohort for Sahod. Each row links one
named user to a real Stellar testnet public key, a role, and a written feedback
note. The same roster is mirrored in the linked [Google Sheet response export](user-feedback-form.md)
and `docs/submission-proof.json`.

Wallet public keys are generated by `scripts/generate-test-wallets.mjs` and funded
via Friendbot. Roles follow the Sahod atomic salary-splitter model: `employer` (the
wallet that signs one paycheck into the contract) or `payee` (a recipient of a share),
with a handful of `reviewer` rows for the audit lens.
